# Jordy Vandewalle — CV

An interactive online résumé, presented in three distinct design languages.
Open `index.html` for the gallery, or jump straight to a variant:

| | Variant | Style |
|---|---|---|
| 01 | [`curriculum.html`](curriculum.html) | **Playful** — neo-brutalist, breakable shapes, confetti |
| 02 | [`curriculum-noir.html`](curriculum-noir.html) | **Editorial** — dark, serif, cursor spotlight, film grain |
| 03 | [`curriculum-glass.html`](curriculum-glass.html) | **Glass** — iOS glassmorphism widgets, light/dark toggle |

Pure static HTML/CSS/JS — no build step, no dependencies.

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
